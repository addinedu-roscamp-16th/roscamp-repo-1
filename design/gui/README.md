# OneTeam 스마트 레스토랑 GUI 디자인 시안

다중 로봇 협업 기반 스마트 레스토랑 자동화 시스템의 화면 디자인 시안입니다.
**실제 앱 코드가 아니라 참고용 시안**입니다. 버튼을 눌러도 화면이 바뀌거나 서버와 통신하지 않습니다.

## 폴더 구성

```
screens/          화면 하나당 HTML 파일 하나. 브라우저로 바로 열립니다.
design-source/    디자인 캔버스 원본 파일(.dc.html). 데이터와 동작 로직이 들어 있습니다.
```

- K·T 화면은 태블릿 가로형(16:10) 비율의 약 932×572px로 그려져 있습니다. 실제 기기 해상도에 맞게 늘려서 구현해 주세요.
- 관리자 화면(A1~A3)은 1440×900px 기준입니다.
- 매장 맵(M)은 원본에서는 탑뷰/3D 전환, 경로 필터, 재생/일시정지가 동작하지만, `screens/`에는 한 순간을 찍은 정지 화면만 들어 있습니다. 동작 로직은 `design-source/Map3D.dc.html`의 `<script>` 안에 있습니다.

- 가격, 메뉴 사진, 시각, 주문 번호 등은 모두 예시 값 또는 자리표시(`[가격]`)입니다.

### design-source/

디자인 캔버스에서 쓰는 형식이라 브라우저에서 바로 열리지는 않습니다.
화면에 들어가는 예시 데이터(테이블 목록, 알람 목록 등)와 매장 맵의 동작 로직은 각 파일 아래쪽 `class Component` 안의 `renderVals()`에 있습니다.

## 디자인 규칙 (고객 화면 K·T)

- 배경 흰색, 면 색 `#F4F5F7`, 본문 글자 `#191C21`, 보조 글자 `#5C6370`
- 포인트 주황 `#F0640F` (주 버튼 배경), 주황 글자 `#C2410C`, 연한 주황 `#FFF1E7`
- 글꼴 Noto Sans KR, 제목 36~44px 800, 자간 -0.02em
- 화면 하나에 질문 하나, 하단에 꽉 차는 주 버튼(높이 72~76px), 터치 영역 최소 44px
- 상단 바: 매장 로고 · (T 화면) 테이블 번호 배지 · 진행 단계 · 직원 호출
- 안내 로봇 캐릭터는 인라인 SVG로 그려져 있습니다. 화면마다 표정과 동작이 다릅니다.

## 클로드 코드로 구현할 때

예시 요청:

> `design/screens/`의 K1~K4 시안을 보고 React + TypeScript로 입구 키오스크 앱을 만들어 줘.
> 색상·글자 크기·간격은 시안과 똑같이 맞추고, 로봇 캐릭터 SVG는 컴포넌트로 분리해 줘.
> 화면 전환은 K1 → K2 → K4 순서이고, 로봇이 없으면 K2 → K3 → K4야.
